stuff i've made

six things i've built and still look after. they all started as something i wanted for myself, which is probably why they actually got finished.

  1. live

    loom

    a past paper library for nsw students. over 7,000 papers from more than 100 schools, sorted by school, year and course, with search across all of it and a pdf viewer right in the page, so you never end up with forty downloads named "trial_final(2).pdf".

    more

    most of it is maths, because that's where the demand is, but english, chemistry, physics, biology, economics and more are in there too. the whole catalogue ships as one static index, so search is instant and there's no server to fall over the week before trials.

    javascript · pdf.js · static site loom.neonxsl.dev
  2. live

    echo

    a local music player in the browser, built entirely around the keyboard. point it at a folder and it plays mp3, aac, flac and alac, with vim-style navigation, search, shuffle and synced lyrics. the tab key is banned.

    more

    chromium can't play apple lossless, so echo decodes alac to wav on the fly without losing quality. folder access and track metadata get cached in indexeddb so it isn't re-parsing your whole library every launch, and the glow around the album art follows the bass on an exponential curve so it moves smoothly instead of flickering.

    javascript · web audio · indexeddb echo.neonxsl.dev
  3. live

    typo

    a minimal typing test you can only drive with the keyboard. xp and levels, daily streaks, live wpm graphs, and leaderboards for every gamemode so you can see exactly where you rank against your friends.

    more

    six spoken languages, tamil included, plus javascript, python and go modes that switch to a monospace font and give an xp multiplier for being harder. sign in with github and your progress syncs through appwrite, so your stats follow you between devices.

    javascript · chart.js · appwrite typo.neonxsl.dev
  4. live

    space tab

    a new tab page that's actually worth looking at. every morning it pulls a fresh astronomy picture from nasa, so opening a tab usually means a nebula, a launch, or a planet you weren't expecting.

    more

    underneath it's deliberately plain: google search wired straight in, a few themes to match your browser, and aggressive caching so the image never gets in the way of whatever you opened the tab for. i use it dozens of times a day, which makes every rough edge impossible to ignore.

    javascript · css · nasa api space.neonxsl.dev
  5. live

    sapphire

    a grade tracker made for nsw students. add your marks and it does the rest: weighted subject averages, upcoming exams, and your sentral timetable in the same place, so you're not checking three apps to work out where you're meant to be.

    more

    the maths was easy, the interface wasn't. school data is messy and the people using it are stressed and on their phones between periods, so everything important had to be visible without a single tap. it taught me more about designing for real, impatient people than anything else i've made.

    typescript · react · mongodb sapphire.neonxsl.dev
  6. open source

    quartz

    a paper plugin that gives 1.21.11 minecraft servers real-time metrics. tick rate, memory, entity and chunk counts: the numbers you want when the server starts stuttering and everyone in chat is asking why.

    more

    a monitor that costs performance is worse than no monitor, so collection runs light and stays off the main thread wherever it can. it started as a debugging aid for a server i ran with friends, then turned out to be useful to other people too.

    java · paper api · minecraft github.com/neonxsl/quartz

  7. and a pile of smaller stuff

    plugins, bots, scripts and experiments that never got their own card.

    github.com/neonxsl

about

the short version: i build things i want to exist, and i look up a lot.

i write code in sydney, mostly for the web, and mostly because i want something to exist and nobody's made it quite the way i'd like.

it started with html in a text editor because i wanted a bit of the internet that was mine. now it's most of what i do. i like building pages from scratch, getting the type right, and making sure it still works on a phone with one bar of signal. the bits nobody notices are my favourite part: nothing jumping around while it loads, buttons that respond straight away. good software is quiet, and quiet takes way more work than you'd think.

outside the browser i write python and java, and i've been doing more swift lately. pretty much everything starts as a problem i have. sapphire exists because tracking marks for six subjects in a notes app was miserable. quartz exists because i wanted to actually see what my minecraft server was doing instead of guessing.

i'd rather ship one small thing that works properly than five that almost do.

when i'm not coding i'm reading about spaceflight, following launches i have no business caring this much about, or outside with binoculars trying to find something faint. hence the sky up there.
